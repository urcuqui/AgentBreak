About

AgentBreak is a local educational lab for breaking, observing, hardening, replaying and regression-testing AI applications and tool-using agents. Both labs are fully simulated: no LLM API, no network access, no real data.

Principles

  • Retrieved content is data, not authority.
  • Influence ≠ impact.
  • Security controls live outside the model.
  • Same attack, different posture.
  • Every successful AI attack should become a security test.

AgentBreak is intentionally vulnerable and was built for educational and defensive security research. All data is fictional. No external calls.
